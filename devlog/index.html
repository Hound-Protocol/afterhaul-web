0.0.107latest, 2026-11-02

Early work in progress. Characters, animations and maps shown here are temporary stand-ins for testing, not final art. Page built 2026-11-02 14:49 UTC.

Mon 02 Nov 202617 versions

  1. 0.0.107-preA handoff noteLatest

    • A current handoff note now lets any new work session continue exactly where the last one stopped: what is tested, what is not, how to run the engine's own checks, and what comes next.

  2. 0.0.106-preA briefing note

    • A short briefing note now lists the new optional animation features, how to try them, and how to return to the tested version.

  3. 0.0.105-preAn activity clock

    • The top-right indicator now runs a ten-minute clock. It says Working with a short note while the team is active, switches to Offline and Not being worked on after ten quiet minutes, and always shows a ticking "Developer last active" time.
    • A lost internet connection shows separately as No connection.

  4. 0.0.104-preThe dev log updates itself

    • New versions now pop into an open dev log within about a minute, with a toast, an updated counter and gauge, and no reload.
    • The top-right indicator shows your connection (Offline or Reconnecting), recent activity, and a "Working" label with a short note while the team is on something.

  5. 0.0.103-preClearer working principles

    • The project's working rules now include four short principles for careful, minimal and checkable changes, adapted from a public guideline set.

  6. 0.0.102-preMore polish for the dev log

    • Clips and pictures open in an animated viewer, and cards pop into place when you search or filter.
    • Every version has a Copy link button, and opening a version by its link flashes it. A back-to-top button, press-feedback on the filter buttons and a "/" key that jumps to search were added.
    • The title, text and gauge ease in when the page opens, and the gauge needle idles.

  7. 0.0.101-preDev log on the website, by link only

    • The dev log is on the website again, with no button. It opens only from its own address, so only people given the link can find it.
    • The travelling marker on the road now stays on the road line and no longer runs over any text.

  8. 0.0.100-preA redesigned dev log

    • The dev log now has an instrument cluster with a rolling version counter and a gauge, a road with a marker that travels as you scroll, and cards that glide in.
    • Search, a pictures-and-clips filter and a milestones filter find any version at once. Clips and pictures open full size.

  9. 0.0.99-preThe dev log goes private

    • The dev log now lives behind a private link shared by the team, not on the public website, with an entry for every version.

  10. 0.0.98-preA reusable code check

    • A code check that catches typing and syntax mistakes in the test scripts before they reach the game engine is now part of the project.

  11. 0.0.97-preLeaning into turns

    • An optional lean makes the character tilt into turns, so turning looks less stiff. Off until the owner tries it.

  12. 0.0.96-preWhat we learned, written down

    • New pages gather what was found out so far and a plain how-to for the engine, so nothing learned is lost.

  13. 0.0.95-preDev log for friends

    • A small button on the website opens this dev log: every version so far, newest first, with pictures and clips on the version they were made in.
    • The team now writes down lessons from every tricky fix, plus a findings page and an engine how-to, so the same mistake is not made twice.

  14. 0.0.94-preWalk baseline locked in

    • The animated walk is confirmed as the base for the character: clean, upright and without sliding.

  15. 0.0.93-preFeet on the ground

    • A live setting lifts the character a little, so the soles stop sinking into the floor.

  16. 0.0.92-preFlatter feet

    • While a foot is planted it now turns flat against the ground, so the toes stop pointing up.

  17. 0.0.91-preThe walk stops sliding

    • The walking speed now comes from the walk animation itself, so the feet match the ground instead of skating.
    • The character no longer hovers above the floor.

Sun 01 Nov 202616 versions

  1. 0.0.90-preFirst animated walkMilestone

    • The character plays a real walking animation on the test map, moved with the keyboard.

  2. 0.0.89-preClearer test messages

    • Fixed a message that vanished, so the test screen now says whether the animations are running.

  6. 0.0.85-preA steadier pose

    • Standing still now holds one clean pose instead of walking on the spot.

  7. 0.0.84-preAnimation and physics stop fighting

    • The animation system is switched off while the physical body is in control, which stops the body from collapsing.

  8. 0.0.83-preAnimation clips can drive the body

    • The hidden copy of the character can now play ready-made animation clips, and the physical body follows it. A temporary test clip is used.

  11. 0.0.80-preLegs that step

    • A hidden copy of the character is posed by code: each foot plants, lifts and steps to a new spot, and the physical legs copy it.

  12. 0.0.79-preLess swimming

    • The walking push is spread over the whole body, so it no longer tips forward or drags the limbs.

  13. 0.0.78-preFirst physical walk

    • The physical body can be steered with the keyboard, turns to face its direction and swings its legs.

  14. 0.0.77-preStanding and hits confirmed

    • Tests on the real character confirm the body stands, reacts to a hit and recovers.

  15. 0.0.76-preFaster test updates

    • One command now brings the latest test scripts to the developer's computer.

  16. 0.0.75-preFixing the hover

    • Settings added to bring the feet down onto the ground.
