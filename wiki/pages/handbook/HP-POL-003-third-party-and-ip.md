# Third-Party Assets and IP Policy
Code: HP-POL-003 · Version 1.1 · Effective 2026-11-02 · Owner: Owner · For: everyone who adds code, art, audio or text
Audience: Makers
Summary: Use only work we own or hold a licence for, and record every third-party item.

## 1. Purpose
AFTERHAUL stays independent by using only original work and properly licensed work. This policy turns that into working rules. It is not legal advice.

## 2. Rules
1. **Original or licensed.** Everything in the project is made by us or used under a licence that allows our use.
2. **Check before you use.** Read the licence of any code, font, model, texture or sound before you add it.
3. **Nothing copied.** No code, assets or audio from other games or leaked sources. Nothing imitates another game's assets, logos or characters.
4. **No generative AI** art, music, sound or voices ([HP-POL-002](HP-POL-002-ai-use-policy.md)).
5. **Record it.** Add each third-party item and its licence to the third-party notices file in the same change that adds it.
6. **No purchase without the owner's yes.** Check a pack's contents and licence first.

## 3. Kinds of source
| Source | Rule |
|---|---|
| Open-source code or fonts with a compatible licence | May be used with credit, with the licence kept |
| Code without a licence | Read for understanding only. Copy nothing |
| Licences we cannot accept (for example "no commercial use") | Do not use |
| Asset Store packs | Standard Asset Store licence: use inside the game only. Do not hand out the files |
| Free-tool outputs (for example animation libraries) | Read the current terms first. Redistribution and use for machine learning are often forbidden |

### Can I use it? Examples
| You found | Answer |
|---|---|
| A free font under the SIL Open Font License | Yes. Credit it and keep the licence |
| A texture on a forum with no licence stated | No. No licence means no permission |
| A sound clip "free for personal use" | No. The game is not personal use |
| A model pack from the Asset Store | Only after the owner says yes and the licence is read |
| Code from a tutorial with no licence | Read it to learn. Write your own |

## 4. Asset files
- Keep bought or downloaded asset files out of git and out of any public repository.
- Each team member downloads their own copy. One licence covers one entity.
- Some terms are unclear. Example: whether animation clips shipped inside a game count as redistribution is unknown. Read the current terms before release.
