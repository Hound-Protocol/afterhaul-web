# Glossary
Group: Technical

Public terms for AFTERHAUL and how we work. Game terms for players are in the [player glossary](player-glossary.md).

## Game terms
| Term | Meaning |
| --- | --- |
| Operations Chief | The player who hosts the session and leads the crew |
| Operator | A player who joins the Chief's session and plays a class |
| Class | An Operator specialty. There are eight |
| Crew | The Chief and the Operators |
| Employer | A character who gives jobs |
| Contract | A job from an employer |
| Nuts | The currency |
| Ledger | The tablet app that logs help between players |
| Region | One of the maps. Names are working names |

## Project terms
| Term | Meaning |
| --- | --- |
| Concept | The first release stage. Planning and groundwork. Nothing is playable |
| Alpha | The first playable version, for invited testers |
| Beta | Most of the game is in. More players try it |
| Release | The finished first version |
| Unity | The game engine. We use Unity 6.3 LTS |
| Proton | Valve's tool for running Windows games on Linux |
| Active ragdoll | A body of joined parts moved by motors, so it can stumble and recover |
| Module | One piece of the game built and tested on its own |
| Unverified | Code that has not run in Unity yet |
| Data mod, script mod | Two kinds of mod. Script mods run code and turn achievements off |
| Handbook | The guides, policies and procedures |
| Library | The overview, plans and reference pages |
| Confidence | How sure we are of a research claim: confirmed, likely or unknown |
| Hound Protocol | The studio that makes AFTERHAUL |
| AI-assisted | Work made with help from an AI tool, and disclosed as such |
