# Frequently Asked Questions
Group: Project

Short answers about the project. Questions about playing are in the [player guide Q&A](player-faq.md).

## The game
**What is AFTERHAUL?**
A co-op offroad trucking game for up to eight players. See the [Overview](overview.md).

**Can I play it?**
No. It is at the Concept stage. Nothing is playable yet.

**When will it come out?**
Not decided yet. We set dates only when a stage is close. See the [Roadmap](roadmap.md).

**Which platforms?**
The first builds target Windows. We want the Windows build to run on Linux through Proton. That is not tested yet. A native Linux build is planned after release.

**Can I join a stranger's game?**
No. There are no open sessions. The Chief of each crew chooses who joins.

## The project
**Is AFTERHAUL open source?**
No. It is proprietary and all rights are reserved. See [Licensing](licensing.md).

**Do you use AI art, music or voices?**
No. People make or license all final art and audio. One temporary AI-made placeholder cover picture is on the site until real art replaces it. AI may help with planning, text and tools, and we disclose it. See the [AI Use Policy](../handbook/HP-POL-002-ai-use-policy.md).

**Will there be mods?**
Yes, planned. See [Making a mod](player-modding.md).

**Is there a Discord?**
Not yet. The community server is on hold until the game has a prototype.

**Can I help?**
Only invited members work in the project. Testers will be invited during closed tests. See [Contributing](contributing.md).

**How do I follow progress?**
Read the [Changelog](changelog.md) and the [Roadmap](roadmap.md).

**Where are the player questions?**
How it plays, crews and mods: see the [player guide Q&A](player-faq.md).

**What do the words mean?**
See the [Glossary](glossary.md) and the [player glossary](player-glossary.md).

**How do I report a problem or a security issue?**
For a bug in the website, use the contact address in the Press section. For a security issue, follow the [Security Policy](security.md) and do not post it in public.

**What does the site store about me?**
Very little. See [Privacy](privacy.md).

**Can I use the logo?**
Only as the [Brand](brand.md) page allows.

**Who do I contact?**
Use the contact address in the Press section of the website.
