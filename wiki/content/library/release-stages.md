# Release stages
AFTERHAUL moves through four stages. Dates for every stage are to be announced. Dates are announced once each stage is close.

## Concept (current stage)

Currently in progress. The design is written and the rules are being built and tested. Nothing is playable yet.

## Alpha

A rough, playable version: one truck, one region and a small crew. Invited testers help find what breaks.

## Beta

Most of the game is in. The beta opens on Steam so more players can try it and report problems.

## Release

The finished first version, ready for everyone.
