# Glossary
Project, process and wiki terms for AFTERHAUL. Words about playing are in the [player glossary](player-glossary.md). Terms here are listed once; game terms are repeated only when the wiki uses them outside the player guide.

## Game terms
| Term | Meaning |
| --- | --- |
| Operations Chief | The player who hosts the session and leads the crew |
| Operator | A player who joins the Chief's session and plays a class |
| Class | An Operator specialty. There are eight. See [Character classes](character-classes.md) |
| Crew | The Chief and the Operators |
| Employer | A character who gives jobs |
| Contract | A job from an employer |
| Nuts | The currency |
| Ledger | The tablet app that logs help between players |
| Region | One of the maps. Names are working names. See [Regions](player-regions.md) |
| Surface | The ground under a wheel, such as mud or ice. See [Ground surfaces](player-surfaces.md) |
| Mount point | A place on a truck where one part can be fitted |
| Driver | The body you play. It is physical and can stumble and get up |

## Release terms
| Term | Meaning |
| --- | --- |
| Concept | The first release stage. Planning and groundwork. Nothing is playable |
| Alpha | The first playable version, for invited testers |
| Beta | Most of the game is in. More players try it |
| Release | The finished first version |
| Pre-release (`-pre`) | A version number ending in "-pre". It comes before release |
| Changelog | A dated list of results, newest first |
| Roadmap | The plan by stage, with a status on each item |
| Closed test | A test for invited people only |
| Stand-in | A temporary picture or clip that is not final art. It is labelled |

## Technical terms
| Term | Meaning |
| --- | --- |
| Unity | The game engine. We use Unity 6.3 LTS |
| Proton | Valve's tool for running Windows games on Linux |
| Native build | A version made for one system, such as Linux, without Proton |
| Active ragdoll | A body of joined parts moved by motors, so it can stumble and recover |
| Physics | The rules for weight, grip, damage and motion |
| Module | One piece of the game built and tested on its own |
| Edit Mode test | A game-logic test run inside Unity without playing |
| Compile check | A check that code builds against small stand-ins for Unity. It does not prove the game works |
| Unverified | Code that has not run in Unity yet |
| Repository | A project's folder of files and history, kept on GitHub |
| Commit | One saved step of work |
| Sign-off | The `git commit -s` line that says you may submit the work |
| Pull request | A request to add your work. The owner reviews it |
| Data mod, script mod | Two kinds of mod. Script mods run code and turn achievements off |
| Mod | A change or addition made by players. Planned, not built yet |

## Project and policy terms
| Term | Meaning |
| --- | --- |
| Hound Protocol | The studio that makes AFTERHAUL |
| Owner | The founder, TrueMan, who has the final say |
| Proprietary | All rights reserved. Not open source. See [Licensing](licensing.md) |
| Open source | Code anyone may copy under a licence. AFTERHAUL is not this |
| Third-party | Made by someone else. It needs a checked licence |
| Notices file | The list of third-party items and their licences |
| Organisational assistant | The only role AI has on AFTERHAUL: it helps plan, take notes, tidy documents and keep work organised. People decide and make everything creative |
| Generative AI | AI that makes art, music, sound or voices. AFTERHAUL does not use it for final art, music, sound or voices. One temporary placeholder cover picture is the only exception |
| AI-assisted | Work made with help from an AI tool, and disclosed as such |
| Disclosure | Saying openly where AI helped |
| Confidential | Not to be shared outside the team |
| Code of Conduct | The rules for behaviour. See [Code of Conduct](conduct.md) |
| Dev log | A public results-only log kept at an unlisted address |
| Unlisted | Not linked from the site and hidden from search engines |

## Wiki terms
| Term | Meaning |
| --- | --- |
| Library | The overview, plans and reference pages |
| Handbook | The guides, policies and procedures |
| Group | The label on a Library page: Project, Technical, Community, Legal or Player guide |
| HP-GDE | Handbook guide |
| HP-POL | Handbook policy |
| HP-SOP | Handbook standard procedure |
| Audience | Who a Handbook page is for: Players, Makers, Quality or Owner |
| Draft | A page that may still change |
| Confidence | How sure we are of a research claim: confirmed, likely or unknown |
| Not decided yet | The honest answer when a choice has not been made |
