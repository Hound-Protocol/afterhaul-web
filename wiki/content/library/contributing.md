# Contributing
AFTERHAUL is a closed Hound Protocol project. The game repository is private and proprietary. Only invited members work in it.

## Can I help?
- **Not invited yet:** you can follow progress on the [Roadmap](roadmap.md) and the [Changelog](changelog.md). The community server is on hold.
- **Invited:** read the [Contributor Quick Start](../handbook/HP-GDE-003-contributor-quick-start.md) and the [Contributor Policy](../handbook/HP-POL-001-contributor-policy.md).
- **Testing:** closed tests come with Alpha. Invitations are not open yet.

## Rules for members
- **Confidential.** Do not copy, post, screenshot or describe the design, code, data or assets outside the team. The public site shows marketing content and the player guide only.
- **Sign off every commit** (`git commit -s`). It certifies that you wrote the work or have the right to submit it, and that it belongs to Hound Protocol under the project licence.
- **Credit AI tools.** Keep the `Co-Authored-By` trailers. Say so in the pull request when AI helped. See the [AI Use Policy](../handbook/HP-POL-002-ai-use-policy.md).
- **Original work only.** Use no assets, code or audio you do not own or have licensed. No generative AI images, music, sound or voices. See [Third-party and IP](../handbook/HP-POL-003-third-party-and-ip.md).
- **One module at a time.** Work follows the module plan. A module is done when it works in its test scene and passes its checks.
- **Design first.** A design change updates the design document in the same commit.
- **Changelog.** Every change worth noting gets a changelog line, and the version moves with it.
- **Be kind.** The [Code of Conduct](conduct.md) applies.

See also [Pull Request and Review](../handbook/HP-SOP-002-pull-request-review.md) and [Bug Triage](../handbook/HP-SOP-005-bug-triage.md).
