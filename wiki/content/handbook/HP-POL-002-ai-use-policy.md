# AI Use Policy
## 1. Position
On AFTERHAUL, AI is an organisational assistant. It helps plan, take notes, tidy and organise documents, keep checklists and operate tools. People decide and make everything creative: design, art, music, sound and voices. AI agents work as tools of the person using them. Hand-written and AI-assisted work are checked the same way. The one hard limit is creative content: **generative AI images, artwork, music, sound effects and voices are never used** (section 5).

What counts is that the work is correct, original, licensed and checked.

## 2. You are responsible
- You are the author of what you submit, whatever tools you used. You must understand it well enough to explain and fix it.
- Run it and test it before it is merged. Code that has not run in Unity is marked unverified.
- "The AI wrote it" is never an answer in review.

## 3. Disclosure
- Say when AI tools wrote or substantially changed code, text or content. Name the tool in one line.
- Keep the agent's commit trailers (`Co-Authored-By`). Removing them on purpose breaks this policy.
- Text from a helper AI is logged. Helper AI gets text-only jobs and never sees the design, code or tuned numbers.
- Work done with an agent is credited to the person, with the agent named. Agents hold no authority.

## 4. Code and text
| Allowed | Not allowed |
|---|---|
| Generating, refactoring and explaining code | Asking an AI to reproduce code from another game or a leaked source |
| Writing tests, tools and documentation | Submitting code you have not run |
| Turning our own notes into code | Pasting secrets or private files into an AI tool |
| Summarizing public sources in our own words | Copying other projects' text or code |

AI output passes the same checks as any other work.

## 5. Art, music, sound and voices
**The line:** AI may operate tools. AI may not generate creative content.

| Allowed | Not allowed |
|---|---|
| AI working through design tools: layout, resizing, cropping, exporting | Generative AI images, artwork, textures, icons or logos |
| Vector graphics drawn in code | Generative AI music, sound effects or voices, including clones of real people |
| AI helping with text, code, diagrams and charts | Upscaling or "restyling" someone else's art with AI |
| Fonts, photos and assets made by people, under a licence that allows our use | Placeholder art made by an image model |

- Art and audio come from people. We respect the artists whose work image and sound models are built on.
- The owner supplies the audio. Code only plays it. Code never generates sound.
- Placeholder art uses plain shapes until real art exists.
- Voice commands use speech recognition only. There are no synthetic voices.
- Say when an AI operated a tool, for example "Claude laid this out".

### Can I use AI for this?
| Task | Answer |
|---|---|
| Ask an AI to write a function, then run and test it | Yes. Disclose it |
| Ask an AI to tidy the layout of a poster you drew | Yes. It operates a tool |
| Ask an AI to make a logo, icon or texture | No |
| Ask an AI to read out a line of dialogue | No. Voices come from people |
| Paste a log with a token in it into a chatbot | No. Remove the secret first |
| Ask an AI to summarize a public licence page | Yes, then open the page and check it yourself |

## 6. Data and privacy
Never paste into an AI tool: tokens, keys, passwords, private messages or players' personal data.

## 7. Research
- Research notes cite real sources. Check every claim an AI gives you against its source.
- Mark confidence: confirmed, likely or unknown.
- AI summaries must not copy the source's text.

## 8. Breaches
Unreviewed or copied AI output is treated like any other copied or broken work ([HP-POL-001](HP-POL-001-contributor-policy.md), [HP-POL-003](HP-POL-003-third-party-and-ip.md)).
